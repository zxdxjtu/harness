# Evaluator 快速启动指南 — 已有产品打磨场景

> 适用于：已经完成第一版复刻，需要对标参照产品做细节打磨和 UI 优化。

## 前置条件

1. 参照产品（QoderWork）可在本地运行
2. 开发产品（WeWork）可在本地运行
3. Playwright MCP 已配置（在 `.claude/settings.json` 或 MCP 配置中）
4. Harness 插件已安装

## 启动提示词

在 WeWork 代码仓库中，粘贴以下提示词启动完整评估流程：

---

```
我正在复刻 QoderWork，目前已有第一版实现（WeWork），但细节还原度不够。
请帮我启动 Evaluator 对抗评估流程，严格对比两个产品。

参照产品（QoderWork）: http://localhost:5173
开发产品（WeWork）: http://localhost:3000

请按以下流程执行：

### Phase 1: 基线采集
运行 /baseline http://localhost:5173 --depth deep
重点关注：
- 所有页面的完整截图（每个状态）
- 工具栏、侧边栏、面板的精确布局和样式
- 各类工具（编辑器、终端、文件树等）的渲染细节
- 交互动效（hover、focus、transition、动画）
- 响应式布局断点
- 暗色/亮色主题（如果有）
- 空状态、加载状态、错误状态
- 右键菜单、快捷键提示、工具提示（tooltip）

### Phase 2: 对抗评估
运行 /evaluate F001 --ref-url http://localhost:5173 --dev-url http://localhost:3000
评估时请特别严格地检查：
1. **像素级 UI 对比**：字体大小、行高、颜色值、边距、圆角、阴影
2. **交互一致性**：点击、拖拽、resize、滚动行为是否一致
3. **工具渲染**：编辑器语法高亮、终端光标、文件图标是否一致
4. **布局结构**：面板分割、侧边栏宽度、工具栏图标排列
5. **状态管理**：选中态、悬停态、禁用态的视觉反馈

### Phase 3: 修复循环
如果评估分数 < 8（我要求高保真），运行 /eval-fix F001
修复优先级：
- P0: 功能缺失或完全不工作的部分
- P1: 布局和结构性偏差（面板位置、组件层级）
- P2: 样式细节（颜色、字体、间距）
- P3: 交互细节（动效、过渡、hover 效果）

每轮修复后重新评估，直到总分 ≥ 8/10。
```

---

## 注意事项

- 两个产品必须**同时运行**在不同端口
- 基线采集可能需要 10-20 分钟（取决于产品复杂度）
- 评估报告和截图保存在 `.harness/evidence/F001/`
- 可以随时查看 `.harness/evidence/F001/eval-report.md` 了解当前差距
- 用 `/cancel-sprint` 可以随时中止循环
